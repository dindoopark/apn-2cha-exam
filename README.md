# 임상전문간호사 2차 자격시험 정리

임상전문간호사(APN) **2차 자격시험(서술형 사례형)** 대비 학습자료 4종입니다.
국시 강의자료와 2021~2025년 2차 기출 복원 문제를 바탕으로 만들었습니다.

## 구성

**본편**은 목차 순서대로 8개 계통 64개 질환을 다루고, 강의자료에는 있으나 목차에 없던 주제 12개를 부록으로 덧붙였습니다.
각 질환은 항목이 고정되어 있습니다.

> 정의·병태생리 → 위험요인(근거 포함) → 임상양상·신체사정 → 진단(검사와 진단기준) →
> 치료 → 생활습관 관리와 근거 → 합병증·추적관찰 → APN 시험 포인트

치료는 **약물 계열 · 시작~최대용량 · 기전 · 부작용 · 금기 · 모니터링 시점 · 환자교육 문구**까지,
그리고 **치료 성공을 언제 어떻게 판정하는지**까지 적었습니다.
예를 들어 *H. pylori* 제균은 레지멘별 용량·기간에 더해 "치료 종료 4주 후 요소호기검사, PPI는 2주 전·항생제는 4주 전 중단"까지,
혈전용해는 용량·투여법에 더해 "투여 후 24시간 신경학적 사정 15분→30분→1시간, 혈압 <180/105 유지"까지 담았습니다.

**사례 문제집**은 실제 기출의 배점 구조를 본떠 케이스당 100점, 소문항 3~5개로 구성했고,
문항마다 **모범답안 · 채점 포인트 · 해설 · 이렇게 쓰면 감점** 네 블록이 붙어 있습니다.

## 쓰는 법

- 왼쪽 **목차**로 이동, 위쪽 **검색창(Ctrl/⌘+K)** 은 모든 파트를 한 번에 검색합니다.
- **파트 탭**으로 한 계통씩 봅니다(문서가 커서 화면에는 한 파트만 그립니다).
- 오른쪽 위 **⤓ PDF로 저장** → 인쇄 대화상자에서 대상을 "PDF로 저장".
  본편은 수백 페이지라 옆의 **인쇄 범위**에서 파트를 하나씩 골라 나눠 저장하시길 권합니다.
  "배경 그래픽" 옵션을 켜야 색상 강조가 나옵니다.

## 출처 표기

섹션 제목 아래 태그로 근거를 구분해 두었습니다.

- 회색 `출처 guksi_05 p.14` — 강의자료에 근거한 내용
- 주황색 `보강 · GOLD 2025` — 강의자료에 없어 최신 진료지침으로 채운 내용
- `기출 2024 시나리오2` — 실제 기출과 연결되는 부분

강의자료 원문에 부정확한 표기가 있던 부분은 **원문을 그대로 옮긴 뒤 현재 표준을 함께 표시**했습니다.

## 검증

임상 수치(용량·진단 절단값·시간창·점수 배점)는 다중 검증을 거쳤습니다.
검증자가 오류를 지적하면 **다른 검증자가 반박을 시도해 살아남은 것만** 반영했습니다.
이 과정에서 좌우가 뒤집힌 서술, 용법이 뒤바뀐 약물, 위험군별로 엇갈리던 LDL 목표치 등을 바로잡았습니다.
